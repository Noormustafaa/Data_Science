-->Status command .
It Displays The State Of the Code

it will show on branch main .

Note : If You will make change (Modify) Your File Then you have to add and commit as well , these are all things will show status command .
Note And when you create index.html file then you write git status then it will show untracked file . means those files which Git don't know.


So whenever we use git status Generally we face 4 types of status 

1: Untracked 
   new files that git Doesn't yet Track 
2: modified
    means you have make changing 
3: unmodified 
   means you have no make changing  
4: staged
    file is ready to be committed
